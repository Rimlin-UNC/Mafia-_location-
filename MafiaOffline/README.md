# 🎭 Мафия Offline

Приложение для игры в «Мафию»: **сервер работает прямо на телефоне ведущего**,
игроки играют **в обычном браузере** — им ничего устанавливать не нужно.
**Интернет не нужен.**

```
    ВЕДУЩИЙ                          ИГРОКИ
    ┌─────────────┐                  ┌──────────────┐
    │  APK        │  ①  QR Wi-Fi ──▶ │  камера      │
    │  сервер     │                  │  ↓           │
    │  на телефоне│  ②  QR игры  ──▶ │  браузер     │
    └─────────────┘                  └──────────────┘
      раздаёт Wi-Fi                    ничего не ставят
```

Работает на iPhone, Android, планшетах и ноутбуках — нужен только браузер.

Версия **1.0.6**

### Собрать самому

```bash
# (вы уже в папке MafiaOffline — корне проекта)
flutter pub get
flutter build apk --release
```

> **Сборка падает?** Запустите диагностику — она найдёт вашу Java и напечатает
> готовые команды:
> ```powershell
> powershell -ExecutionPolicy Bypass -File docs\проверка-java.ps1
> ```
> - «Unsupported class file major version 69» → Gradle запущен на Java 25.
>   Лечится: `flutter config --jdk-dir "путь к JDK 17"`. См. `docs/ОШИБКА_СБОРКИ.md`.
> - «JAVA_HOME is set to an invalid directory» → путь указывает на несуществующую
>   папку. См. `docs/ОШИБКА_JAVA_HOME.md`.

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`

В `android/gradle.properties` стоят экономные лимиты памяти. На машине с 8+ ГБ
ОЗУ поднимите их — сборка ускорится в разы:

```properties
org.gradle.jvmargs=-Xmx3g -XX:MaxMetaspaceSize=1g
kotlin.compiler.execution.strategy=daemon
```

Для iPhone нужен Mac с Xcode — см. `docs/IOS_BUILD.md`.

## Как играть

**Ведущий** (Android): включает раздачу Wi-Fi → «Я ведущий» → задаёт состав → показывает QR-код.

**Игроки** — два способа:

1. **Через приложение:** «Я игрок» → «Сканировать QR» → имя.
2. **Через браузер:** навести камеру телефона на QR → откроется страница игры. Установка не нужна, работает на iPhone, Android, ноутбуке.

Все устройства должны быть в одной Wi-Fi-сети. Интернет не требуется — достаточно раздачи с телефона ведущего при выключенных мобильных данных.

## Как устроено

```
        ТЕЛЕФОН ВЕДУЩЕГО                      КЛИЕНТЫ
   ┌──────────────────────────┐
   │  HttpServer :8088        │──── GET / ──────▶ 🌐 браузер (iPhone)
   │   ├── статика веб-клиента│──── WS /ws ─────▶ 🌐 браузер (ноутбук)
   │   └── WS /ws → игра      │◀─── WS ─────────▶ 📱 нативный APK
   │  UDP :45455 автопоиск    │
   │  вся игровая логика      │
   └──────────────────────────┘
```

Браузерный и нативный игроки для ведущего неотличимы — говорят одним протоколом и могут играть в одной партии.

**Почему не Bluetooth:** Android ограничивает GATT-соединения константой `BTA_GATTC_CONN_MAX = 7`, на практике стабильны 4–6. WebSocket поверх Wi-Fi держит 20 устройств.

## Возможности

**Партия:** состав 6–20 игроков, 7 ролей, пресеты, валидация баланса, автоматический второй тур при ничьей, история партий в SQLite.

**Роли:** мафия и дон — команда мафии. Доктор, комиссар, проститутка, маньяк и мирный житель — все горожане: у каждого свои ночные особенности, но днём голосуют вместе и хотят вычислить мафию. Порядок разрешения ночи: блокировка → лечение → мафия → маньяк → проверка. Дон выглядит мирным для комиссара.

**Победа — играем до последнего:** город выигрывает, когда выбыл последний мафиози; мафия — когда против неё остался один игрок. Состав 3 на 3 не блокируется. На экране создания игры индикатор оценивает шансы сторон (пороги откалиброваны по симуляции сотен партий).

**Приватность:** роль приходит только своему устройству; экран-предупреждение перед раскрытием; режим маскировки — карта показывает мирного жителя, если кто-то заглянёт через плечо.

**Звук:** 20 файлов, синхронизированы между устройствами через NTP-подобную оценку смещения часов (разброс 2–4 мс при 20 игроках).

**Устойчивость:** ping каждые 5 с, 3 автопопытки переподключения, возврат в свой слот по имени, восстановление партии после перезапуска приложения, работа при выключенном экране.

## Что осталось непроверенным

Всё тестировалось статическим анализом и симуляцией — **физических телефонов у меня не было**. Перед первой игрой обязательно проверьте на реальных устройствах:

1. **Сканер QR** — в версии 1.0.2 он ронял приложение, причина найдена и устранена, но подтвердить на железе я не мог.
2. **Работа при выключенном экране** — служба переднего плана должна удерживать соединения.
3. **Звук в Safari на iPhone** — браузер глушит аудио при блокировке экрана.
4. **Партия на 20 устройствах** — сеть проверялась только моделированием.
