# 🎭 Мафия Offline

Приложение для игры в «Мафию»: **сервер работает прямо на телефоне ведущего**,
игроки играют **в обычном браузере** — им ничего устанавливать не нужно.
**Интернет не нужен.**

```
    ВЕДУЩИЙ                          ИГРОКИ
    ┌─────────────┐                  ┌──────────────┐
    │  APK        │  ①  QR Wi-Fi ──▶ │  камера      │
    │  сервер     │                  │  ↓           │
    │  на телефоне│  ②  QR игры  ──▶ │  браузер     │
    └─────────────┘                  └──────────────┘
      раздаёт Wi-Fi                    ничего не ставят
```

Работает на iPhone, Android, планшетах и ноутбуках — нужен только браузер.

Версия **1.6.1+13** · последний собранный APK — **1.6.1** (см. ниже)

## Как играть

**Ведущий** (Android): включает раздачу Wi-Fi → «Я ведущий» → задаёт состав → показывает QR-код.

**Игроки** — два способа:

1. **Через приложение:** «Я игрок» → «Сканировать QR» → имя. С 1.4.0 первый код ведущего — **единый**: в нём и сеть Wi-Fi, и вход в игру. Приложение (Android 11+) по нему само подключается к сети и входит — одно сканирование.
2. **Через браузер:** навести камеру телефона на первый код — подключится Wi-Fi; на второй (вкладка «Для браузера» у ведущего) — откроется страница игры. Установка не нужна, работает на iPhone, Android, ноутбуке. Одного кода для браузера сделать нельзя: камера по одному QR делает одно действие (`docs/CHANGELOG_1.4.0.md`, §1).

Все устройства должны быть в одной Wi-Fi-сети. Интернет не требуется — достаточно раздачи с телефона ведущего при выключенных мобильных данных.

## Как устроено

```
        ТЕЛЕФОН ВЕДУЩЕГО                      КЛИЕНТЫ
   ┌──────────────────────────┐
   │  HttpServer :8088        │──── GET / ──────▶ 🌐 браузер (iPhone)
   │   ├── статика веб-клиента│──── WS /ws ─────▶ 🌐 браузер (ноутбук)
   │   └── WS /ws → игра      │◀─── WS ─────────▶ 📱 нативный APK
   │  UDP :45455 автопоиск    │
   │  вся игровая логика      │
   └──────────────────────────┘
```

Браузерный и нативный игроки для ведущего неотличимы — говорят одним протоколом и могут играть в одной партии.

**Почему не Bluetooth:** Android ограничивает GATT-соединения константой `BTA_GATTC_CONN_MAX = 7`, на практике стабильны 4–6. WebSocket поверх Wi-Fi держит 20 устройств.

## Возможности

**Партия:** состав 6–20 игроков, 7 ролей, пресеты, валидация баланса, автоматический второй тур при ничьей, история партий в SQLite.

**Роли:** мафия и дон — команда мафии. Доктор, комиссар, проститутка и мирный житель — город. Маньяк — одиночка со своей победой. Порядок разрешения ночи: блокировка → лечение → мафия → маньяк → проверка. Дон выглядит мирным для комиссара; доктор не лечит себя и одну цель две ночи подряд.

**Победа — классика (с 1.1.0):** город выигрывает, когда не осталось ни мафии, ни маньяка; мафия — когда её столько же, сколько горожан, или больше; маньяк — оставшись единственным живым; если не выжил никто — ничья. На экране создания игры индикатор оценивает шансы сторон.

**Правила стола (с 1.2.0):** четыре переключателя при создании партии — открывать ли карту выбывшего, первая ночь — знакомство (никто не погибает), последнее слово и повторное голосование, комиссар видит результат проверки у себя. Игроки видят правила своего стола по кнопке «Правила».

**Последнее слово и повторное голосование (с 1.3.0):** тот, кого выбрал стол, ещё не выбыл. Он говорит 30 секунд, после чего все, кроме него, голосуют ещё раз — выгнать или оставить. Выбывает, только если «выгнать» больше; поровну — остаётся. Убедил стол — играет дальше.

**Проверка комиссара (с 1.3.0):** ответ появляется у комиссара на экране сразу, как он выбрал игрока, — один раз за ночь. Если в игре жива проститутка и она ещё не сходила, ответ приходит в момент её хода: блокировка отменяет проверку.

**Экран игрока (с 1.2.0):** счётчик «Живых: N из M», правила и условия победы внутри игры, вибрация при смене фазы — одинаковая у всех ролей.

**Приватность:** роль приходит только своему устройству; экран-предупреждение перед раскрытием; режим маскировки — карта показывает мирного жителя, если кто-то заглянёт через плечо.

**Звук:** 20 файлов, синхронизированы между устройствами через NTP-подобную оценку смещения часов (разброс 2–4 мс при 20 игроках).

**Устойчивость:** ping каждые 5 с, 3 автопопытки переподключения, возврат в свой слот по имени, восстановление партии после перезапуска приложения, работа при выключенном экране.

## Что осталось непроверенным

Всё тестировалось статическим анализом и симуляцией — **физических телефонов у меня не было**. Перед первой игрой обязательно проверьте на реальных устройствах:

1. **Сканер QR** — в версии 1.0.2 он ронял приложение, причина найдена и устранена, но подтвердить на железе я не мог.
2. **Работа при выключенном экране** — служба переднего плана должна удерживать соединения.
3. **Звук в Safari на iPhone** — браузер глушит аудио при блокировке экрана.
4. **Партия на 20 устройствах** — сеть проверялась только моделированием.
5. **Правила стола 1.2.0 и 1.3.0** — ночь знакомства, последнее слово
   и повторное голосование, ответ комиссару на ночном экране, «Ваши
   проверки», счётчик живых. Логика покрыта тестами, но на экране телефона
   этого никто не видел. Первая партия — проверочная.
6. **Вибрация при смене фазы** — на Android должна работать; Safari на iPhone
   вибрацию из браузера не поддерживает.
