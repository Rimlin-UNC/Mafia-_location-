# Веб-клиент: игра в браузере по QR-коду

Игроки заходят в партию **через браузер** — сканируют QR у ведущего и играют. Ставить приложение не нужно: работает на iPhone, Android, планшете, ноутбуке.

---

## Важное решение: Flask + ngrok не нужны

Вы предложили поднять Flask и пробросить через ngrok. Я этого **не делал**, и вот почему.

**Flask не запустится на Android.** Python на телефоне живёт только в Termux — это отдельное приложение, его пришлось бы ставить каждому ведущему и запускать сервер вручную из консоли. Для игры за столом это неприемлемо.

**ngrok противоречит вашему же требованию.** Это туннель через интернет: трафик уходит на серверы ngrok и возвращается обратно. Вы указали «только локальная сеть, без внешнего интернета» — ngrok здесь лишний и в офлайне просто не заработает.

**Сервер уже есть.** В приложении с самого начала работает HTTP-сервер на `dart:io` (порт 8088) — тот, через который подключается нативный клиент. Он лишь отдавал заглушку «откройте приложение» вместо страницы. Я научил его раздавать веб-клиент — **новых процессов и зависимостей ноль**.

```
        ТЕЛЕФОН ВЕДУЩЕГО                      КЛИЕНТЫ
   ┌──────────────────────────┐
   │  HttpServer :8088        │──── GET / ──────▶ 🌐 браузер (iPhone)
   │   ├── GET /  → index.html│──── WS /ws ─────▶ 🌐 браузер (ноутбук)
   │   ├── GET /cards/*.jpg   │
   │   ├── GET /sounds/*.ogg  │◀─── WS ─────────▶ 📱 нативный APK
   │   └── WS  /ws → игра     │
   │  UDP :45455 автопоиск    │
   └──────────────────────────┘
```

Браузерный и нативный игроки для ведущего неотличимы — они говорят одним протоколом и могут играть в одной партии одновременно.

## Как развернуть

Ничего разворачивать не нужно — всё внутри APK.

1. **Ведущий** включает раздачу Wi-Fi на телефоне и создаёт игру.
2. На экране лобби появляется QR и адрес вида `http://192.168.43.1:8088`.
3. **Игроки** подключаются к этой раздаче Wi-Fi.
4. Наводят камеру на QR → открывается браузер → вводят имя → играют.

Код партии подставляется из ссылки (`/?g=482913`), вводить его вручную не нужно. Если камеры нет — адрес можно набрать руками, он написан под кодом.

Интернет не требуется ни на одном этапе. Wi-Fi-раздача работает и при выключенных мобильных данных.

## Что умеет веб-клиент

Полный паритет с нативным приложением:

| Возможность | Как реализовано |
|---|---|
| Подключение | Код из QR-ссылки, имя вводится один раз |
| Карта роли | Те же иллюстрации, переворот по тапу |
| Маскировка | Кнопка «Скрыть роль» — карта показывает мирного жителя |
| Экран-предупреждение | «Убедитесь, что никто не смотрит» перед раскрытием |
| Справка по ролям | Задача, действия ночью и днём, условие победы, советы |
| Ночные действия | Список целей, отправка, блокировка после хода |
| Голосование | Список кандидатов, второй тур |
| Синхронный звук | NTP-оценка смещения часов, Web Audio API |
| Атмосферный фон | Зацикленные лупы фаз |
| Режим зрителя | Лог событий после выбывания |
| Возврат в игру | `localStorage` + reclaim по имени на сервере |
| Обрыв связи | Ping 5 с, 3 автопопытки переподключения |
| Правила (1.2.0) | Кнопка с книгой в лобби и в партии: правила этого стола, победа, роли |
| Счётчик живых (1.2.0) | «Живых: N из M» под таймером; по нажатию — список стола без ролей |
| Проверки комиссара (1.2.0) | Только внутри «Моя роль»; при маскировке скрыты |
| Ночь знакомства, последнее слово (1.2.0) | Свои заголовки фазы; сигнал вибрацией одинаков у всех |

## Ограничения

- **Только HTTP, без TLS.** Браузер покажет «незащищённое соединение» — для локальной сети это нормально. Сертификат для `192.168.x.x` выпустить нельзя, а самоподписанный вызвал бы страшное предупреждение.
- **Звук требует жеста.** Браузеры не дают играть аудио до первого касания. Разблокировка происходит при нажатии «Подключиться» — специально ничего делать не нужно.
- **iOS Safari глушит фон при блокировке экрана.** Игрок должен держать вкладку открытой; при возврате состояние синхронизируется автоматически.
- **Не тестировалось на реальных телефонах.** Проверял эмулятором протокола и статическим анализом — камеры и мобильных браузеров в песочнице нет. Первым делом проверьте на живых устройствах сканирование QR и звук на iPhone.
