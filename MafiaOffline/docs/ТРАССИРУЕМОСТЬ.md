## Журнал допущений и ADR

| ID | Решение | Причина |
|---|---|---|
| ADR-001 | Транспорт: локальный Wi-Fi + WebSocket вместо Nearby Connections (вариант C вместо B из ТЗ) | Кроссплатформенность (iPhone в браузере), простота, нет зависимости от Play Services. BLE отвергнут (лимит 7). |
| Доп-1 (FR-3.5) | Защита роли: экран-предупреждение + маскировка вместо удержания пальца | Эквивалентная защита от подглядывания, проще в браузере (Safari). |
| Доп-2 | ~~Маньяк — на стороне города (v1.0.4+)~~ **отменено в v1.1.0** | Заказчик вернул классику: маньяк — одиночка со своей победой. Старое значение `Side.solo` теперь снова используется по назначению, а не только для чтения истории. |
| ADR-002 | Фаза `rolesCheck` добавляется в `GamePhase` вместо флага «роли розданы» | Одно состояние вместо двух источников истины; фаза видна клиенту и сохраняется в `SessionStore` без новых полей. Ломающее изменение только для исчерпывающих `switch` — проверено, все с `default`. |
| Доп-3 (FR-3.6) | Гейт первой ночи: автостарт при 100% подтверждений + аварийная кнопка | См. `OPEN_QUESTIONS.md`, вопрос 2 | 
| Доп-4 (FR-2.10) | Переименование посреди партии запрещено по умолчанию | См. `OPEN_QUESTIONS.md`, вопрос 3: пакет `lobby` широковещательный, смена имени — сигнал столу |
| ADR-003 | Переподключение без верхней границы попыток | Сдаваться через 6 секунд на точке доступа ведущего — гарантированная потеря игрока. Бесконечный цикл с растущей паузой и разбросом — та же логика, что уже проверена в веб-клиенте |
| Доп-5 (FR-2.11) | `deviceId` — случайная строка в настройках, а не аппаратный ID | Не собираем отпечатки и не выходим за NFR-10. Нужен только чтобы отличить «он пришёл с планшета» от «кто-то занял имя» |
| Доп-6 (FR-3.9) | Автозапуск ночи — настройка, но гейт 100% не отключается | Опытным столам не нужен лишний шаг; новичкам нужен гейт. Настройка меняет только «кто нажимает кнопку» |
