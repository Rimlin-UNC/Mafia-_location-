# Установка «Мафия Offline»

## Android — готовые файлы

| Файл | Размер | Кому |
|---|---|---|
| **MafiaOffline-universal.apk** | 37 МБ | **берите этот**, работает на любом телефоне |
| MafiaOffline-arm64.apk | 24 МБ | только телефоны 2018+, легче |

Файлы выросли: добавился сканер QR (Google ML Kit) и служба фоновой работы.

### Как поставить

1. Скачайте APK на телефон.
2. Откройте файл — Android спросит разрешение на установку из неизвестных источников. Разрешите.
3. При первом запуске приложение попросит доступ к камере (для сканера QR) и к уведомлениям (для фоновой работы). Разрешите оба.

## Как играть

**Ведущий** (нужен Android): включает раздачу Wi-Fi → «Я ведущий — создать игру» → задаёт состав → показывает игрокам QR-код.

**Игроки**: подключаются к этой раздаче Wi-Fi → «Я игрок — подключиться» → **«Сканировать QR»** → наводят камеру на экран ведущего → вводят имя.

Код можно ввести и вручную — сканер не обязателен.

Интернет не нужен никому. Важно лишь, чтобы все были в одной Wi-Fi-сети.

## Что нового

- **Сканирование QR-кода.** Кнопка на экране подключения. Из кода читается и номер партии, и адрес ведущего — подключение мгновенное, без поиска по сети. Есть фонарик для тёмной комнаты.
- **Один профиль на телефон.** После входа приложение помнит, что вы уже в игре. На стартовом экране вместо формы регистрации появляется «Вы играете как …» с кнопками «Вернуться в игру» и «Выйти».
- **Работа при выключенном экране.** Сервер ведущего больше не умирает, когда телефон гаснет: работает служба переднего плана с уведомлением в шторке, экран удерживается от засыпания, Wi-Fi не уходит в сон.
