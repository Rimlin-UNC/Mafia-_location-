# 1.14.0 — личная доска подозрений

- Кнопка «Мои подозрения» у сетевого игрока в Flutter и ✎ в браузере.
- Для каждого другого участника: «? Подозреваю», «✓ Доверяю» или без отметки, текст до 500 символов.
- Выбывшие остаются в блокноте. Переименование не теряет запись: ключ — ID, не имя.
- Записи хранятся только на устройстве (SharedPreferences / localStorage), отдельно от модели Player, протокола и состояния ботов. Изолированы по адресу ведущего, коду стола и ID автора.
- Блокнот не заполняется автоматически результатами проверок: предположение не выдаётся за установленный факт.
- При отказе хранилища интерфейс предупреждает, что запись временная.
- Браузер закрывает приватную шторку при уходе в фон.

Ограничения: заметки не шифруются и доступны владельцу устройства; очистка данных приложения/браузера удаляет их. Для локального игрока на телефоне ведущего блокнот пока не предусмотрен. Это не архив партий: при повторном использовании того же кода и ID записи могут сохраниться.

Проверки: тесты локального хранения и повреждённых данных; браузерный smoke-тест приватности, переименования, выбывания, экранирования текста и изоляции автора.
